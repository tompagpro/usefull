**Usefull** is a web application designed to help organize and manage URLs efficiently by categorizing them and applying tags for easy accessibility.
This application allows users to store, categorize, and retrieve URLs based on their specific interests and needs.

* *Technologies Used* 

    **Backend**: Nest JS
    **Database**: PGSQL
    **Frontend**: React.js (TS)
    **Authentication**: JSON Web Tokens (JWT)
